Instal Aplikasi (PWA)

SmartKasir bisa diinstal di layar utama dan dibuka offline setelah kunjungan pertama.

Aplikasi sudah terinstal / siap dipakai dari layar utama.

Panduan Android (Chrome)
  1. Buka halaman ini di Chrome.
  2. Ketuk menu ⋮ di kanan atas.
  3. Pilih Tambahkan ke Layar Utama / Instal aplikasi.
  4. Ketuk Instal — ikon biru “K” muncul di layar utama.
Panduan iOS (Safari)
  1. Buka halaman ini di Safari.
  2. Ketuk tombol Share (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama.
  4. Ketuk Tambah — SmartKasir tampil seperti aplikasi.

Deploy Statis (GitHub Pages / Vercel)

  1. Simpan file ini sebagai index.html beserta folder assets/ (manifest, service worker, ikon) dalam satu repo, mis. smartkasir.co.id.
  2. Push ke GitHub, lalu di Vercel pilih Import Project → repo tersebut → Framework: Other → Deploy. Di GitHub Pages: Settings → Pages → branch main.
  3. Tidak ada build step, server, atau database — semua file statis relatif.
